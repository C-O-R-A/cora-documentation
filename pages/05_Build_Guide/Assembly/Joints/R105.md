## Build Steps

1. **Motor and Controller**
<video autoplay loop muted playsinline style="width:100%;border-radius:8px;margin:16px 0;">
  <source src="../../../../_static/assets/videos/1_.webm" type="video/webm">

Attatch the bldc-motor and controller to motor mount, then connect the motor coils to the correct terminals as shown.

> [!Warning]
> If you connect the motor coils in a different order, make sure to take note of it if recalibration or disassembly is ever needed.

2. Run motor calibration.

3. Attatch stage 1 planetary gearbox.
<video autoplay loop muted playsinline style="width:100%;border-radius:8px;margin:16px 0;">
  <source src="../../../../_static/assets/videos/2_A.webm" type="video/webm">
</video>
> [!NOTE]
> Assemble the gearbox such that all the arrows point inward and all the round holes point in the same direction

4. Assemble and mount stage 2.
